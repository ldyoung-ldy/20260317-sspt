## 一、环境准备

### 1.1 本地开发环境

```bash
# 1. 克隆项目
git clone <repo-url>
cd 20260317-sspt

# 2. 安装依赖
bun install

# 3. 配置环境变量
cp .env.sample .env.local
# 编辑 .env.local，填写以下必要配置：
#   DATABASE_URL    — 数据库连接字符串
#   AUTH_SECRET     — Auth.js 密钥（可用 openssl rand -base64 32 生成）
#   ADMIN_EMAILS    — 管理员邮箱列表（逗号分隔）
#   AUTH_GOOGLE_ID  — Google OAuth Client ID
#   AUTH_GOOGLE_SECRET — Google OAuth Client Secret

# 4. 初始化数据库
bun run db:migrate

# 5. 启动开发服务器
bun run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可访问。

### 1.2 生产环境

生产环境已部署至 Vercel：**https://sspt-ai.vercel.app/**

## 二、角色说明

平台有三种角色，权限逐级递增：

| 角色 | 入口 | 权限范围 |
|------|------|----------|
| **参赛者** | 首页 → 登录 | 浏览赛事、报名、提交作品、查看排名 |
| **评委** | 评审中心 | 对分配的赛事作品进行评分 |
| **管理员** | 管理后台 | 创建/管理赛事、审核报名、管理作品、分配评委、发布排名 |

> **如何成为管理员？** 在 `.env.local` 的 `ADMIN_EMAILS` 中添加你的 Google 登录邮箱。

## 三、管理员操作指南

### 3.1 登录与进入后台

1. 点击右上角 **「登录」** → 使用 Google 账号登录
2. 登录后导航栏出现 **「管理后台」**，点击进入

![管理后台概览](screenshots/admin-dashboard.png)

### 3.2 创建赛事

1. 进入 **管理后台 → 赛事管理**
2. 点击右上角 **「创建赛事」**
3. 填写赛事信息：
   - **基础信息**：赛事名称、描述、面向对象
   - **时间窗口**：赛事开始/结束时间、报名截止时间
   - **赛道设置**：添加一个或多个参赛赛道
   - **评分维度**：设置评审打分维度及权重
   - **奖项设置**：配置奖项名称与说明
4. 点击 **「保存」**，赛事将以 **草稿** 状态创建

### 3.3 发布赛事

1. 在赛事列表中找到目标赛事
2. 点击 **「发布」** 按钮
3. 发布后，赛事将出现在前台首页，参赛者可开始报名

> ⚠️ 已发布的赛事可以取消发布回到草稿状态。仅未发布且无关联数据的赛事可删除。

### 3.4 报名审核

1. 在赛事列表中点击 **「报名管理」**
2. 查看报名统计（总数/待审核/已通过/已拒绝）
3. 操作选项：
   - **单条审核**：逐条接受或拒绝
   - **批量操作**：勾选多条后批量接受/拒绝
   - **导出 CSV**：导出报名数据

### 3.5 作品管理

1. 在赛事列表中点击 **「作品管理」**
2. 可按状态（草稿/终稿）、赛道筛选
3. 查看作品详情（描述、源码链接、演示链接、视频）
4. 导出 CSV

### 3.6 评审管理与排名发布

1. 在赛事列表中点击 **「评审管理」**
2. **分配评委**：添加评委的邮箱
3. 查看评分覆盖率和当前排名
4. 所有评分完成后，点击 **「发布排名」** 将榜单公示到前台

![赛事管理列表](screenshots/admin-events.png)

## 四、参赛者操作指南

### 4.1 浏览赛事

1. 访问首页查看当前开放的赛事
2. 点击赛事卡片进入详情页
3. 查看赛事时间线、赛道、赛题、奖项、评分维度

### 4.2 报名参赛

1. 在赛事详情页，点击 **「立即报名」**（需先登录）
2. 填写报名信息（队伍名称、自定义字段等）
3. 提交后状态为 **「待审核」**
4. 管理员审核通过后，状态变为 **「已录取」**
5. 进入 **「我的报名」** 页面，点击 **「确认参赛」**

![我的报名](screenshots/my-registrations.png)

### 4.3 提交作品

1. 确认参赛后，进入赛事详情页点击 **「提交作品」**
2. 填写作品信息：
   - 作品名称与描述
   - 选择参赛赛道与赛题
   - 填写源码链接、演示链接、视频链接等
3. 可先保存为 **草稿**，在提交窗口关闭前提交 **终稿**
4. 在 **「我的作品」** 页面追踪所有作品状态

![我的作品](screenshots/my-projects.png)

### 4.4 查看排名

排名发布后，在赛事详情页底部可查看公开榜单。

## 五、评委操作指南

### 5.1 进入评审中心

1. 登录后，导航栏出现 **「评审中心」**（仅被分配了评审任务时可见）
2. 查看被分配的赛事及评审进度（待评/已评数量）

![评审中心](screenshots/judge.png)

### 5.2 对作品评分

1. 点击 **「进入评审」** 进入单赛事评分页
2. 左侧展示终稿作品列表（含待评/已评状态标记）
3. 点击作品查看详情
4. 右侧按评分维度逐项打分（1-10 分），填写评语
5. 点击 **「保存评分」**，可反复修改直到评审窗口关闭

## 六、常见问题

### Q: 登录后看不到「管理后台」入口？

确保你的 Google 登录邮箱已添加到 `.env.local` 的 `ADMIN_EMAILS` 环境变量中。修改后需重启开发服务器。

### Q: 报名按钮是灰色的？

检查赛事是否在报名窗口期内（当前时间需在报名截止时间之前）。

### Q: 提交作品时显示「不在提交窗口内」？

作品提交有时间窗口限制，需在赛事设定的提交时间范围内操作。

### Q: 评委看不到「评审中心」？

评委需要由管理员在后台「评审管理」中分配。分配后刷新页面即可看到入口。

### Q: 如何删除赛事？

仅 **未发布** 且没有报名、作品、评分等关联数据的赛事可以删除。已发布赛事需先取消发布。

## 核心流程速览

```
管理员创建赛事 → 发布赛事
                    ↓
        参赛者浏览 → 报名 → 等待审核
                    ↓
        管理员审核报名 → 通过
                    ↓
        参赛者确认参赛 → 提交作品（草稿 → 终稿）
                    ↓
        管理员分配评委
                    ↓
        评委评分打分
                    ↓
        管理员发布排名 → 前台公示
```
